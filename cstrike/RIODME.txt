SOBRE SUPORTE A 32 JOGADORES
----------------------------
A versao 1.4 eh TOTALMENTE COMPATIVEL com as versoes anteriores (1.0, 1.1, 1.2 e 1.3)
Para 32 jogadores, apenas o servidor precisa estar com a versao 1.1 ou superior.
Ou seja, NINGUEM precisa atualizar o seu cs_rio para jogar em servidores
de 32, basta o servidor estar atualizado.  Os jogadores apenas precisas fazer
o upgrade para poder ver o mapa no novo modo espectador introduzino no CS 1.4.

SOBRE BOTS
----------
Esta versao do cs_rio ja contem waypoints para o PodBot.
Basta instalar o PodBot 2.5 (http://www.nuclearbox.com/podbot/)
e iniciar um jogo LAN, selecione o cs_rio que os bots devem aparecer.
Use a tecla "=" (sinal de igual) para acessar o menu de bots.

ABOUT 32 PLAYER SUPPORT
-----------------------
The version 1.4 is TOTALLY COMPATIBLE with all older version (1.0, 1.1, 1.2 and 1.3)
ONLY THE SERVER needs to be updated for a 32 players game. The players DON'T NEED
TO UPDATE their cs_rio to join a 32-player server, they can connect with the original
cs_rio. The players just need to upgrade to be able to watch the map in the new
spectator mode introduced on CS 1.4.
